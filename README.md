# 📝 To-Do List

A simple desktop To-Do List application built with **Python** and **CustomTkinter**.

This project was created as a personal programming project to practice Python, object-oriented programming, GUI development, event handling, and saving application settings using JSON.

## 📌 Features

- 📝 Add tasks
- 👀 View tasks
- ✏️ Edit tasks
- 🗑️ Delete tasks
- ⚙️ Settings menu
- 🌙 Light/Dark mode
- 🎨 Color theme selection
- 💾 Persistent settings using JSON
- 🔄 Remembers selected settings when the application is reopened

## 🛠️ Built With

- **Python**
- **CustomTkinter** - GUI framework
- **JSON** - Persistent settings storage
